# Stundenbuch

Zeiterfassung, Stundenzettel, Urlaub und Überstunden in einer Android-App.

## Herunterladen

**[Stundenbuch 2.7 herunterladen](https://github.com/games-yves-mrichter-droid/stundenbuch-updates/raw/main/Stundenbuch.apk)**

1. Link auf dem Android-Handy öffnen und die Datei herunterladen.
2. Datei antippen und installieren (beim ersten Mal „Installation aus dieser Quelle erlauben“).
3. Neue Versionen meldet die App danach selbst – Einstellungen → App & Updates.

Deine Daten bleiben nur auf deinem Handy. Hier liegt ausschließlich die App.
